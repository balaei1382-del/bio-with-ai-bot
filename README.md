# 🤖 ربات همه‌فن‌حریف کانال Bio with AI

ربات خودکار و **کاملاً رایگان** کانال [@Bio_with_AI](https://t.me/Bio_with_AI):

- 🔀 **چند کلید AI با تعویض خودکار:** هر تعداد کلید جمینای + هر سرویس سازگار با OpenAI
  (Grok/xAI، OpenRouter، DeepSeek، OpenAI و…) را بدهید؛ اگر یکی به محدودیت (429) خورد
  یا خراب شد، خودکار می‌رود سراغ بعدی و کلیدِ خسته را ۹۰ دقیقه کنار می‌گذارد.
- 📚 **چهار نوع محتوا:**
  - `news` → تازه‌های زیست‌شناسی، هوش مصنوعی در زیست، و کامپیوتر/محاسبات در زیست (از ۱۰ منبع معتبر)
  - `tip` → ترفندهای عملی بیوانفورماتیک (ابزار واقعی + لینک مستندات رسمی)
  - `roadmap` → رودمپ کامل ورود به حوزه یک **مقاله علمی واقعی و تازه** (bioRxiv، PLOS، Nature)
  - `tool` → معرفی ابزار/سرور/پایگاه داده بیوانفورماتیک (از ۴۰ ابزار واقعی با لینک رسمی)
- 🖼 **تصویر هوش مصنوعی مرتبط با همان متن** (ساخت با جمینای) + ارسال با کپشن
- 🔗 **هر پیام منبع واقعی دارد** و در انتهای هر پیام **لینک کانال** می‌آید
- 🔁 حافظه ضدتکرار (لینک‌های پست‌شده ذخیره می‌شوند)
- 🎚 ایموجی سنجیده، سطح علمی دانشگاهی، فارسی روان

## مرحله ۱: ساخت ربات در تلگرام

1. سرچ: **@BotFather** (آکانت رسمی) → بفرستید `/newbot`
2. نام: مثلاً `Bio with AI Poster` — یوزرنیم: مثلاً `bio_with_ai_poster_bot`
3. توکن (`123456...:AAH...`) را ذخیره کنید 🔐

## مرحله ۲: ادمین کردن ربات در کانال

کانال → **Administrators → Add Admin** → یوزرنیم ربات → فقط دسترسی **Post Messages** را روشن بگذارید.

## مرحله ۳: گرفتن کلیدهای هوش مصنوعی (هر چند تا که خواستید!)

می‌توانید از چند سرویس همزمان کلید بگیرید و همه را بدهید:

| سرویس | کجا کلید بگیریم | هزینه |
|---|---|---|
| **Google Gemini** | [aistudio.google.com](https://aistudio.google.com) → Get API key | رایگان (بدون کارت) |
| **xAI / Grok** | [console.x.ai](https://console.x.ai) | ارزان (grok-4.1-fast) |
| **OpenCode Zen** | [opencode.ai/auth](https://opencode.ai/auth) → کلید بگیرید | مدل `grok-code-fast-1` رایگان |
| **OpenRouter** (ده‌ها مدل رایگان) | [openrouter.ai](https://openrouter.ai) | مدل‌های علامت `:free` رایگان‌اند |
| **DeepSeek** | [platform.deepseek.com](https://platform.deepseek.com) | خیلی ارزان |
| **OpenAI** | [platform.openai.com](https://platform.openai.com) | پرداختی |

💡 **ترفند:** با چند اکانت گوگل می‌توانید چند کلید رایگان جمینای بگیرید — دقیقاً همان چیزی که برای «کمبود منابع» می‌خواهید. OpenRouter هم یکجا به مدل‌های رایگان (مثل DeepSeek، Llama، Qwen با پسوند `:free`) دسترسی می‌دهد.

### قالب `AI_CONFIG` (یک Secret برای همه کلیدها)

فایل نمونه: `AI_CONFIG.example.json` — برای شش کلید جمینای + xAI + دو OpenCode Zen:

```json
{
  "gemini_models": ["gemini-3-pro", "gemini-2.5-pro", "gemini-2.5-flash"],
  "gemini": [
    { "api_key": "جمینای-۱" },
    { "api_key": "جمینای-۲" },
    { "api_key": "جمینای-۳" },
    { "api_key": "جمینای-۴" },
    { "api_key": "جمینای-۵" },
    { "api_key": "جمینای-۶" }
  ],
  "openai_compatible": [
    { "base_url": "https://api.x.ai/v1",        "api_key": "xai-...",    "model": "grok-4.1-fast" },
    { "base_url": "https://opencode.ai/zen/v1", "api_key": "sk-...",     "model": "grok-code-fast-1" },
    { "base_url": "https://opencode.ai/zen/v1", "api_key": "sk-...",     "model": "grok-code-fast-1" }
  ]
}
```

- `gemini_models` = اولویت مدل برای **همه** کلیدهای جمینای: اول Proها (کیفیت بالاتر،
  سهمیه رایگان کمتر) و بعد Flash (سهمیه بزرگ). هر کلید جدا هم می‌تواند `"models"` خودش را داشته باشد.
- تعداد کلیدها محدودیتی ندارد؛ **ترتیب نوشتن = ترتیب اولویت**.
- تصویرسازی با کلیدهای جمینای انجام می‌شود.
- هر سرویس «سازگار با OpenAI» دیگری فقط با `base_url` + `model` جدید اضافه می‌شود.

## مرحله ۴: ساخت مخزن GitHub

ساختار دقیق مخزن (همه فایل‌ها در **ریشه** ریپو):

```
نام-ریپو/
├── bot.py                    ← مغز ربات (لازم نیست دست بزنید)
├── AI_CONFIG.example.json    ← نمونه تنظیم کلیدها (کلید واقعی داخلش نگذارید!)
├── requirements.txt
├── README.md                 ← همین راهنما
├── .github/workflows/post.yml
└── state/posted.json
```

راه سریع: فایل `bio-with-ai-bot.zip` را Extract کنید، داخل پوشه شوید، **همه محتویات داخلش** را
انتخاب کنید (نمایش فایل‌های مخفی را روشن کنید تا `.github` دیده شود) و روی صفحه
**Add file → Upload files** بکشید.

راه دستی: `bot.py` و `requirements.txt` را Upload کنید؛ سپس با **Add file → Create new file**
دو فایل تودرتو بسازید (تایپ `/` در کادر نام، پوشه می‌سازد):
`.github/workflows/post.yml` و `state/posted.json` (با محتوای `{ "links": [], "topics": [] }`).

✅ معیار درستی: بعد از Commit، تب **Actions** باید ورک‌فلو **«Post to Telegram»** را نشان دهد.

## مرحله ۵: ثبت Secretها

**Settings → Secrets and variables → Actions → New repository secret:**

| Name | Value |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `AI_CONFIG` | کل JSON بالا با کلیدهای واقعی شما |

(اگر ترجیح می‌دهید فعلاً فقط یک کلید جمینای بدهید، Secret ساده‌ی `GEMINI_API_KEY` هم هنوز پشتیبانی می‌شود.)

## مرحله ۶: تست و راه‌اندازی 🚀

1. تب **Actions → Post to Telegram → Run workflow**
2. در پنجره بازشده می‌توانید انتخاب کنید:
   - **post_type**: `auto` (پیش‌فرض، انتخاب وزنی) یا `news` / `tip` / `roadmap` / `tool`
   - **with_image**: ساخت تصویر روشن/خاموش
3. بعد از ۱–۳ دقیقه، پست باید در کانال باشد: 🖼 تصویر + کپشن، سپس متن کامل + منبع + لینک کانال.

از این پس ربات هر روز بین **۲۰ تا ۳۰ پست** (پخش‌شده از ۶:۳۰ صبح تا ۲۱:۰۰ تهران) خودکار می‌گذارد.

## ⚙️ شخصی‌سازی

### نسبت انواع محتوا (پیش‌فرض: ۵ خبر، ۲ ترفند، ۲ رودمپ، ۱ ابزار)
در `.github/workflows/post.yml` بخش env اضافه کنید:
`CONTENT_MIX: "news:4,tip:3,roadmap:2,tool:1"`

### ساعت و تعداد پست‌ها (پیش‌فرض: ۲۰ تا ۳۰ پست در روز)
- ورک‌فلو هر ۳۰ دقیقه (۶:۳۰ تا ۲۱:۰۰ تهران) اجرا می‌شود.
- خود ربات هر روز صبح یک **هدف تصادفی بین ۲۰ تا ۳۰ پست** انتخاب می‌کند؛
  وقتی به آن رسید، اجراهای بعدی همان روز رد می‌شوند. یعنی تعداد پست‌ها
  هر روز کمی متفاوت و طبیعی است.
- تغییر بازه: در `post.yml` مقدار `DAILY_MIN` و `DAILY_MAX` را عوض کنید.
- اجرای دستی از تب Actions به‌صورت پیش‌فرض سقف را نادیده می‌گیرد (پست الزامی).

### منطق اولویت کلیدها
به همان ترتیبی که در `AI_CONFIG` نوشته شده‌اند؛ برای جمینای هر کلید اول
مدل‌های Pro را امتحان می‌کند و اگر سهمیه رایگان آن‌ها تمام شده باشد (خطای 429)،
خودکار Flash می‌شود و بعد کلید بعدی می‌رود.

### گزینه‌های دیگر (در env فایل workflow)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `WITH_IMAGE` | `1` | `0` = بدون تصویر |
| `FULL_TEXT_AFTER_IMAGE` | `1` | `0` = فقط تصویر+کپشن کوتاه، بدون پیام متنی جدا |
| `MAX_AGE_DAYS` | `7` | حداکثر عمر اخبار/مقالات |
| `BASE_TAGS` | … | هشتگ‌های ثابت انتهای پست |
| `CHANNEL_ID` | `@Bio_with_AI` | شناسه کانال |

### افزودن منبع خبری / ابزار
در `bot.py`: لیست `FEEDS` (منابع RSS) یا `TOPIC_BANK` (ابزارها برای ترفند/معرفی).

## 🔁 منطق تعویض خودکار کلیدها (Failover)

1. موتورها به همان ترتیبی در `AI_CONFIG` آمده‌اند امتحان می‌شوند.
2. خطای **429/سهمیه تمام‌شده** → آن کلید ۹۰ دقیقه «خنک» می‌شود و بلافاصله کلید بعدی می‌آید.
3. کلید **نامعتبر (401/403)** → رد می‌شود و در لاگ مشخص است.
4. خطای گذرا (شبکه/سرور) → تا ۲ بار تلاش مجدد، بعد کلید بعدی.
5. اگر همه کلیدها خنک باشند → همه دوباره آزاد می‌شوند و از اول امتحان می‌شوند.
6. تصویرسازی جدا از متن است: اگر مدل تصویری کلید اول جواب نداد، کلیدهای دیگر جمینای را امتحان می‌کند؛ اگر هیچ‌کدام نشد، پست **متنی** ارسال می‌شود (هرگز پست لغو نمی‌شود).

## 🔧 رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `chat not found` / `Forbidden` | ربات ادمین کانال نیست (مرحله ۲) |
| `هیچ‌کدام از موتورها پاسخ ندادند` | کلیدها را در AI_CONFIG چک کنید؛ در لاگ، خطای هر موتور نوشته شده |
| در لاگ `⛔ کلید ... نامعتبر` | آن کلید حذف یا جایگزین شود |
| Gemini خطای 429 | طبیعی است؛ کلید بعدی خودکار می‌آید. کلید/اکانت بیشتر اضافه کنید |
| تصویر ساخته نشد | پست بدون تصویر ارسال می‌شود؛ مدل تصویری رایگان گاهی شلوغ است — مهم نیست |
| پست‌ها با تأخیر | زمان‌بندی GitHub تا ~۳۰ دقیقه تأخیر دارد |
| قطع بعد از ~۲ ماه | GitHub ریپوهای غیرفعال را می‌خواباند؛ هر چند هفته یک تغییر کوچک یا Run دستی |
